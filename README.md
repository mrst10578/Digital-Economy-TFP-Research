# Digital Economy × TFP Research

پروژه‌ی تحلیل اقتصادسنجی برای بررسی رابطه اقتصاد دیجیتال و بهره‌وری کل عوامل تولید، با مسیر اجرای Python.

## وضعیت فعلی

| بخش | وضعیت |
|---|---|
| ساختار پروژه Python | آماده |
| ورود و کنترل داده | آماده |
| پاک‌سازی و Audit داده | آماده |
| آمار توصیفی و همبستگی | آماده |
| مدل نهایی برآورد | در انتظار توضیح دقیق استاد |
| برآورد و نتایج | در انتظار مدل و داده نهایی |

> مدل نهایی عمداً حدس زده نشده است. بعد از دریافت specification استاد، فقط بخش مدل و آزمون‌های مرتبط تکمیل می‌شود.

## ساختار

- `src/config.py` — تنظیمات پروژه
- `src/data_check.py` — کنترل کیفیت داده
- `src/prepare_data.py` — پاک‌سازی و آماده‌سازی
- `src/model_template.py` — محل پیاده‌سازی مدل نهایی
- `run_analysis.py` — اجرای pipeline
- `data/raw/dataset_template.csv` — قالب ورودی داده
- `demo/` — داده کاملاً مصنوعی برای تست فنی
- `tests/smoke_test.py` — تست سریع زیرساخت
- `site/` — داشبورد نمایشی وضعیت پروژه

## اجرای محلی

```bash
pip install -r requirements.txt
python tests/smoke_test.py
python run_analysis.py
```

برای اجرای pipeline روی داده واقعی، فایل `dataset.csv` را داخل `data/raw/` قرار بده.

## نکته پژوهشی

داده‌های پوشه `demo/` مصنوعی هستند و فقط برای تست فنی استفاده می‌شوند. هیچ عددی از آن‌ها نباید به‌عنوان یافته پژوهش گزارش شود.

## سایت

سایت پروژه به‌صورت استاتیک در پوشه `site/` قرار دارد و برای استقرار روی Cloudflare Pages یا هر static host آماده است.
